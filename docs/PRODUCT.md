# 产品定义与功能矩阵

> 修订：2026-09-29 / R2。2.0 目标规范；未标为基线的内容不代表已实现。

本文是已确认的 OmniStore 2.0 产品目标，不代表目标功能已经实现。实现基线和检查范围见 [STATUS](STATUS.md)。

## 1. 长期定位

OmniStore 是面向个人、家庭、小团队的轻量自部署存储中心。核心模型保持 `Storage Source = 本地真实目录`，采用 Go 模块化单体、SQLite 和嵌入式前端。不为 2.0 引入新的内容存储引擎。

2.0 可以调整旧数据库、API 和界面，但破坏兼容不等于可以删除用户数据。已发布 migration 保持冻结，原 1.x 未完成规划并入 2.0，已完成能力不得被当成新需求重做。

## 2. 两个相互独立的分类维度

**能力作用域**决定在哪里配置：产品服务归站点，访问协议归存储源，文件操作归资源。

**文件管理归属**决定文件放在哪里：系统托管内容放在源根目录的 `.omnistore/`；由用户按路径组织的普通内容仍在普通目录。不能用“站点级”推导“必须放入 `.omnistore/`”。

| 能力 | 作用域 | Source 关系 | 文件组织 | 公开方式 |
| --- | --- | --- | --- | --- |
| 私有文件管理 | User / Resource | 按 Policy 可访问多个源 | 普通目录 | 默认不公开 |
| 公开网盘 | Site | 全站最多绑定一个源 | 该源普通目录 | 可浏览的匿名只读空间 |
| 快速图床 | Site | 全站最多绑定一个源 | `.omnistore/image-bed/` | `/i/{image_id}.{ext}` |
| 静态 HTTP 访问 | Source Protocol | 每个源独立配置一个发布目录 | 普通目录，如 `blog-assets/` | 固定 baseUrl + 相对路径，不列目录 |
| WebDAV、S3 | Source Protocol | 每个源独立开关 | 可授权的普通目录 | 凭据 + Policy |
| Share、Preview、Copy、Move、Trash、Favorite | Resource | 跟随具体资源 | 保持原资源定位 | 继承各自授权规则 |

站点服务数据库标识固定为 `public_drive`、`image_bed`。一个服务只有一个当前绑定，一个源可以被两项服务复用。静态 HTTP 与 WebDAV/S3 一样按源配置；匿名读取由明确的发布范围授权。

## 3. 快速图床与静态资源托管

### 快速图床

解决“上传一张图片，立即得到直链”。登录用户和匿名用户可以使用同一产品；匿名入口由管理员显式开启，默认关闭。上传不要求用户选源或管理目录。公开地址使用随机图片 ID，而不是原文件路径。

只接收经过服务端校验的受支持图片。无需为博客视频而把快速图床扩大成任意文件匿名托管。临时使用直链不等于承诺自动删除：图床有独立保留设置。默认不自动过期；管理员设置保留期时应在上传前展示，并在结果中返回绝对失效时间。

### 静态资源托管

解决“私有管理、公开读取的长期博客资源”。它取代旧讨论中“内部私有图床”的含混概念，但不删除登录用户使用快速图床的能力。

文件名和层级由用户维护；图片、视频位于普通目录。上传、覆盖、移动、删除继续经过目标目录 Policy。登录不自动授予发布目录写权限。通过普通文件管理器、启用的 WebDAV/S3 上传的内容具有相同发布语义，不要求先创建 image 记录。

只在一个明确发布目录内提供公开文件读取，不要求公开盘开启、不要求公开挂载、不要求创建 Share，也不在公开盘首页自动列出。对目录请求返回 404；不列目录不意味着文件保密，知道 URL 的人可以读取。

### 为什么不合并

快速图床以系统生成 ID 组织内容；静态资源以用户路径组织内容。两者只共享安全读取、上传底层工具和必要 UI，不共享“随机改名”或临时过期规则。

## 4. 三种公开服务的边界

公开网盘给人浏览目录；静态资源托管给博客等应用按 URL 读取；Share 给已有资源增加独立授权入口。一个源经不同入口公开时，配置分别生效。静态资源不列目录，不能抵消公开盘对同一普通目录的独立公开。

`.omnistore/` 是例外：所有通用入口和普通目录打包都必须隔离，任何服务复用都不得把图床内部文件暴露为源目录内容。

## 5. 永久非目标

不做远程 Storage Source、S3/WebDAV/SMB 后端存储、集群多节点、Redis/PostgreSQL/外部消息队列、微服务、CAS/Chunk 存储引擎、内容去重、文件历史版本、官方同步盘、端到端加密、插件系统、Office 在线编辑、多人协作或服务端 FFmpeg 转码平台。

浏览器支持的图片、文本、PDF、音视频预览在范围内。静态资源托管不是任意 HTML/JavaScript 应用托管服务。
