# 1.3.0 — Operation Center

状态：Planned

## Goal

管理员可以快速回答：

- 服务正常吗？
- Source 正常吗？
- 空间够吗？
- 最近有没有异常？
- 有什么需要人工处理？

## Dashboard

展示：

- Version / Uptime；
- Database；
- Storage Source 健康；
- Physical/File-record usage；
- Last Reconcile；
- User/Quota；
- Trash；
- Thumbnail Cache；
- Multipart Temp；
- Pending Recovery（如适用）；
- Recent failed audit。

## Maintenance

提供受控入口：

- Source Health Check；
- Reconcile；
- Cache cleanup；
- Expired Multipart cleanup；
- SQLite integrity check。

## Non-goals

不建立：

- Prometheus/Grafana 产品依赖；
- 分布式 tracing 平台；
- 大型 Metrics 存储。

需要外部监控的用户可以通过外围基础设施监控进程/HTTP，而不是让 OmniStore 内置整套观测平台。
