# 1.2.0 — Preview & Sharing

状态：Planned

## Goal

文件不仅可以存储，也可以直接被查看和分享。

## Preview

统一：

```text
File
 ↓
Preview Resolver
 ↓
Renderer
```

首批：

- Image；
- Text；
- Markdown；
- JSON/YAML；
- Code；
- PDF；
- Audio；
- Video；
- Unsupported → Download。

视频/音频必须基于标准 Range/浏览器能力，不建立服务端转码系统。

## Share 2.0

复用 Preview：

- 文件分享直接预览；
- 图片画廊；
- 目录列表；
- PDF；
- 音频；
- 视频；
- 目录流式 ZIP；
- 二维码；
- 更清晰的密码/过期/次数状态；
- 实例名称/品牌信息。

## Out of Scope

- Office 在线编辑；
- 服务端 FFmpeg；
- 在线协作；
- 媒体库/刮削。

## Acceptance

文件管理器和分享页不能各自实现一套完全独立的 Preview Renderer。
