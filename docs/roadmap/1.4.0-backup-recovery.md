# 1.4.0 — Backup & Recovery

状态：Planned

## Goal

管理员可以把 OmniStore 系统状态从旧实例恢复到新实例，并重新关联仍由用户自己保存的真实文件。

## Scope

- 稳定 Backup Format；
- 系统备份导出；
- 新实例 Restore；
- Source Rebind；
- Reconcile；
- 恢复报告；
- 版本兼容检查。

## 不备份真实 Source 内容

OmniStore 管理的可能是 TB 级真实文件。

系统备份只负责 OmniStore 自身状态，真实文件仍由用户自己的 NAS/快照/备份方案负责。

## Migration

Restore 必须明确：

- 备份格式版本；
- 源 OmniStore 版本；
- 当前 OmniStore 是否可读取；
- DB migration 如何执行。

## Acceptance

在一份全新的 data dir 上：

```text
Restore
→ Rebind
→ Reconcile
→ 登录
→ 权限
→ 分享
→ 图床
→ 协议凭据/密钥语义
```

形成可验证闭环。
