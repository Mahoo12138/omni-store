# 1.1.0 — File Experience

状态：In Progress（P0）

## Goal

让 OmniStore 从“可靠地管理文件”进一步成为“日常使用舒服的网盘”。

## P0 — Upload Experience

### Upload Task Manager

统一前端任务基础设施：

- 单文件；
- 多文件；
- Folder Upload；
- 总文件数/总字节数；
- 文件级状态；
- 失败重试；
- 取消；
- 合理 Worker 并发。

### Folder Upload

选择本地文件夹：

```text
blog-images/
├── avatar.png
├── posts/2026/a.webp
└── projects/omnistore/cover.png
```

上传到当前目录后保持根目录和层级。

不通过 ZIP + 服务端解压实现。

第一版允许浏览器无法枚举完全空目录。

### Conflict

批量上传支持统一策略：

- 询问；
- 跳过；
- 覆盖；
- 本次任务全部采用同一策略。

不增加“本地和服务器自动比较/镜像删除”的同步盘语义。

## P1 — File Explorer

- 更完整的多选；
- 批量移动；
- 批量复制；
- 批量删除；
- 批量下载；
- 合理的批量分享入口；
- 外部拖拽上传；
- 内部拖拽移动；
- 右键菜单；
- 排序/显示偏好记忆；
- 最近文件；
- 收藏文件/目录；
- 移动端优化。

## Dependency

```text
relative-path upload API
        ↓
Upload Task Manager
        ↓
Folder / Multi Upload
```

## Out of Scope

- 同步客户端；
- 双向同步；
- 文件版本历史；
- CAS/去重；
- 压缩包在线自动展开；
- 预览系统（进入 1.2）。

## Acceptance

- 目录上传保持非空目录层级；
- 每个文件继续使用现有 crash-safe upload；
- 权限/exclude/quota/lock/reserved name 不能绕过；
- 一个失败文件不会要求重新上传整个目录；
- 数百文件任务有明确进度且 UI 不冻结；
- CI / E2E 全绿。
