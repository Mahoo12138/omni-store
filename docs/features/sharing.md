# 文件与目录分享

文件分享属于 `1.0.0 / V2` 的首发范围。它与公开网盘不同：公开网盘由管理员配置固定挂载路径，分享则由具备目标路径写权限的登录用户为单个文件或目录创建可撤销的临时匿名入口。

## 用户体验

用户在私有文件管理器中点击文件或目录的“创建分享”，可以选择：

1. 可选访问密码；密码为 4–128 个字符。
2. 有效期：永久或 1、7、30、90 天；后端接受最长 365 天的精确时间。
3. 下载次数上限；`0` 表示不限制，目录分享中的每次文件下载分别计数。

创建成功后只向用户展示完整分享 URL，例如 `/s/shr-random`。随机 key 是不透明定位符，用户不需要理解或编辑它。`/app/shares` 集中展示当前用户创建的分享；超级管理员可看到全部分享及其创建者。创建者和管理员可以随时撤销。

## 权限与公开访问

创建分享会扩大匿名访问范围，因此必须对目标文件或整个目录子树具备写权限。仅有读取权限的用户不能创建分享。创建后，公开读取不再依赖创建者的后续访问策略，但以下状态会立即使链接不可用：

1. 分享被撤销、到期或达到下载次数上限。
2. 目标进入回收站；恢复后链接重新可用，并跟随新的恢复路径。
3. 目标被协议入口永久删除，或回收站被永久清理。
4. 存储源被禁用或删除。

同一存储源内移动和重命名会同步分享路径。跨存储源移动也会同步来源与路径。复制不会复制分享关系。

## 公开路由

```text
/s/{share_key}                         分享页面
/share/{share_key}/raw                 根文件内容
/share/{share_key}/raw/{child_path}    目录分享内的文件内容
```

页面先读取公开摘要。受密码保护的分享验证成功后设置最长 12 小时的 `HttpOnly`、`SameSite=Lax` Cookie；Cookie 按分享 key 隔离，使多个分享可在不同标签页同时保持解锁。会话不超过分享自身有效期。目录列表和文件读取都重新校验分享状态、来源状态、路径安全、排除规则和 symlink 拒绝。

公开侧对撤销、过期、次数耗尽、禁用来源和目标缺失统一返回 404，避免用响应差异枚举内部状态。密码错误和短时间尝试过多统一返回 401；同一 IP 与分享在 15 分钟窗口最多尝试 10 次。

## 下载计数与并发

`GET` 文件内容前使用条件更新原子增加 `download_count`；达到上限的并发请求只有仍在额度内的请求可以成功。`HEAD` 用于探测元数据，不消耗下载次数。Range 请求按一次 HTTP GET 计数，不按分片数计数。

分享下载使用流式 `http.ServeContent`，不把完整文件载入内存。响应使用 `Cache-Control: private, no-store`；`download=1` 返回 attachment，否则默认 inline。

## 安全存储与清理

访问密码使用与登录密码相同的 bcrypt 哈希，不保存明文。解锁会话只在 Cookie 中返回随机 Token，SQLite 只保存 Token 哈希。过期会话在校验时惰性清理；撤销分享、删除来源或删除创建者会通过外键级联删除分享及会话。

分享内容不复制、不生成 sidecar，也不在用户存储源写入任何 OmniStore 元数据。真实文件系统仍是内容最终事实来源。

## 审计

创建和撤销记录登录用户与目标路径。匿名下载记录 `share_download`、来源、实际子路径、IP 和 User-Agent；不记录密码、明文会话 Token 或分享 URL 查询内容。普通目录浏览不记录。
