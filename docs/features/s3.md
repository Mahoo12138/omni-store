# S3 兼容接口

S3 不属于 MVP；V1.1 已实现本文件定义的基础对象存储子集，Multipart 继续留在 V1.2。

### MVP 不启动 S3

MVP 不启动 S3 专用端口。

配置中可以预留：

```yaml
server:
  s3_addr: "0.0.0.0:8081"
  s3_enabled: false
```

MVP 行为：

1. `s3_enabled` 默认 `false`。
2. 不监听 `s3_addr`。
3. 不实现任何 S3 路由。

### S3 V1.1 鉴权模型（已实现）

S3 使用独立凭据：

```text
Access Key ID
Secret Access Key
```

不复用：

1. 登录密码。
2. WebDAV Token。
3. 图床 Token。

每个用户可创建一个或多个 S3 Key。

字段：

```text
access_key_id
secret_access_key_encrypted
secret_key_nonce
owner_user_id
name
is_disabled
created_at
last_used_at
```

`access_key_id` 可明文保存。

`secret_access_key` 必须可恢复地加密保存，因为 Signature V4 校验需要用 Secret 重新计算签名。

Secret 加密使用 master key：

```text
OMNISTORE_MASTER_KEY
```

如果没有环境变量，首次创建凭据时生成本地 master key 到
`data.dir/keys/s3-master.key`（权限 `0600`）。该文件必须与 SQLite 一起备份。

支持 Authorization Header 签名和最长 7 天的 SigV4 预签名 URL。请求 scope 的 service
必须是 `s3`，Header 签名允许 15 分钟时钟偏差；用户或单个凭据禁用后立即失效。

网页登录用户通过以下接口管理自己的凭据，每用户最多 10 个：

```text
GET    /api/v1/me/s3-credentials
POST   /api/v1/me/s3-credentials
POST   /api/v1/me/s3-credentials/{access_key_id}/disable
POST   /api/v1/me/s3-credentials/{access_key_id}/enable
DELETE /api/v1/me/s3-credentials/{access_key_id}
```

### S3 V1.1 路由（已实现）

只支持 Path-style：

```text
http://host:8081/{source_id}/{object_key}
```

`source_id` 映射为 Bucket。

不支持 virtual-host-style：

```text
http://{bucket}.host/{object_key}
```

### S3 V1.1 支持范围（已实现）

S3 首版只做常用对象存储子集。

支持：

```text
GET Service / ListBuckets
HEAD Bucket
GET Bucket / ListObjectsV2
HEAD Object
GET Object
PUT Object
DELETE Object
DELETE Multiple Objects
```

不支持：

```text
Bucket ACL
Object ACL
Bucket Policy
Versioning
Lifecycle
Object Lock
Legal Hold
Replication
Notification
Website Hosting
CORS 管理接口
Presigned POST
STS
SelectObjectContent
Multipart Upload
SigV4 signed streaming payload
```

单对象 `PUT` 支持普通签名/`UNSIGNED-PAYLOAD`，以及新版本 AWS SDK/CLI 常用的
`STREAMING-UNSIGNED-PAYLOAD-TRAILER`。尾随 CRC32、CRC32C、CRC64NVME、SHA1 或
SHA256 校验和会在原子落盘前验证。带每块 SigV4 签名的 streaming payload 不在 V1.1 范围。

权限完全复用存储源级 `read_only` / `read_write`：`source_id` 是 Bucket；禁用存储源后
Bucket 不可访问。对象 Key 继续经过路径规范化、排除规则、symlink 拒绝和 WebDAV
持久锁检查。普通目录只是 Key 前缀，不作为对象返回。

兼容目标：

```text
优先兼容 rclone、Cyberduck、S3 Browser、AWS CLI 的基础对象读写场景。
不承诺完整 AWS S3。
```

### S3 V1.2 Multipart

Multipart 放到 V1.2。

支持内容：

```text
CreateMultipartUpload
UploadPart
CompleteMultipartUpload
AbortMultipartUpload
ListParts
UploadId 状态管理
Part 编号和 ETag 校验
临时分片目录
合并失败清理
孤儿分片 GC
```

临时目录：

```text
{data.dir}/tmp/multipart/{upload_id}/
```

状态写入 SQLite。

完成时流式合并到目标存储源。

超过 24 小时未完成的分片由后台 GC 清理。
