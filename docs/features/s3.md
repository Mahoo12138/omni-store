# S3 — 2.0

> 修订：2026-09-29 / R2。2.0 目标规范；未标为基线的内容不代表已实现。

S3 是 Source Protocol Capability。

每个 Source：

```text
s3_enabled
```

Bucket：

```text
bucket = storage_key
```

Path-style：

```text
/{storage_key}/{object_key}
```

ListBuckets 只返回：

- Source enabled；
- S3 enabled；
- credential owner 有 read 权限。

Object write 继续经过：

- Policy；
- exclude；
- reserved namespace；
- symlink；
- quota；
- recovery。

`.omnistore` 永远不能作为对象 key 访问。

保留：

- SigV4；
- Presigned；
- Multipart；
- Multipart recovery。

不追求 AWS S3 完整实现。

## 普通静态目录与内部目录

静态发布目录是普通文件路径：协议开启且凭据/Policy 允许时可以上传、覆盖、移动，静态 URL 随之按普通路径语义变化；协议客户端不需要 image_id。

`.omnistore/` 是系统托管范围，拥有 Source 根读写权限也不能访问。通用读取/浏览按 404 处理，协议层保持各自响应格式与认证行为。列表不含内部项；Copy/Move/DELETE/Multipart 不得间接修改内部数据。静态资源服务开启不自动开启本协议，也不授予匿名 S3/WebDAV 写入。
