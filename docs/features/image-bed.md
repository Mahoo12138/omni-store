# 图床

## 1. 模式

支持：

- 登录用户图床；
- 匿名公共图床（管理员显式开启，默认关闭）。

## 2. Storage Source

登录用户只能选择自己有写权限且允许图床的 Source。

匿名公共图床由管理员指定明确目标，不和某个普通用户身份混淆。

## 3. Token

用户可以创建多个命名图床 Token。

要求：

- 明文只在创建时展示；
- 数据库只保存 hash；
- 可独立撤销；
- 记录最后使用时间；
- 有每用户数量上限。

## 4. 图片校验

图床只接受允许的图片类型，不能只信扩展名或客户端 MIME。

限制登录和匿名的最大图片大小。

## 5. URL

稳定公开 URL：

```text
/i/{image_id}.{ext}
```

不把用户名、真实 Source root 或相对物理路径作为公共 ID。

## 6. 写入与恢复

图床上传复用可靠写入原则：

- journal-first；
- 临时文件；
- fsync；
- 图片记录与 `file_records` 同事务；
- 监听前恢复。

未提交文件不能残留；已提交图片不能被恢复器误删。

## 7. 回收站

网页文件管理器把图床图片移入回收站时：

- 图片记录标记 trash；
- 历史墙隐藏；
- 公开 URL 暂时不可用；
- 恢复后清除标记并同步路径；
- 永久清理删除图片记录。

## 8. 缩略图

缩略图是可重建缓存：

- 最长边按系统策略生成；
- size + mtime 参与失效；
- 并发生成去重；
- 定期清理。

## 9. PicGo

提供兼容上传入口并支持 Token。

协议兼容问题进入真实客户端测试矩阵，而不是增加专用产品分支。
