# 1.0.0 验收清单

本文档给出首个稳定版本 `1.0.0` 的最低完成条件。V1、V2 是同一版本的内部开发阶段，所有阶段条目都通过后才能发布。执行验收时应记录实际版本、环境和结果。

### 安装与初始化

1. Docker Compose 可启动。
2. 二进制可启动。
3. 首次启动必须使用一次性初始化凭据创建超级管理员；错误凭据失败，20 个并发初始化请求最终只能创建一个管理员。
4. 配置优先级正确。
5. public_url 生效。

### 用户与权限

1. 超级管理员可创建普通用户。
2. 普通用户不能进入管理员后台。
3. 管理员可创建、更新、删除访问策略，并为策略绑定多个用户和存储源。
4. 普通用户只能访问其策略授予的存储源。
5. 多策略命中同一存储源时采用更高权限，只读用户不能写。
6. 禁用用户所有入口失效。
7. 子路径规则在单个策略内采用最长路径前缀，多策略取最高权限，且路径段边界匹配正确。
8. 当前目录权限在文件管理器中正确反馈；REST、WebDAV、S3 和登录用户图床执行相同的路径权限检查。
9. 删除、重命名或移动父目录不能绕过其后代的只读规则。

### 存储源

1. 禁止系统目录。
2. 禁止数据目录。
3. 禁止重叠挂载；20 个相同目录并发创建请求，以及父子目录并发创建请求，最终都只能成功一个。
4. root_path 不可修改。
5. 删除存储源不删除物理文件。
6. 禁用存储源后所有入口不可访问。
7. 管理员可设置字节级硬配额，`0` 表示不限；管理员和授权用户看到的实时用量一致。
8. 用量包含已有普通文件和排除路径，不跟随 symlink，也不把严格命名的内部上传临时文件计入最终用量。
9. 把配额降低到当前用量以下不会删除真实文件。

### 文件操作

1. 浏览目录正常。
2. 分页排序正常。
3. 上传同名默认 409。
4. overwrite=true 才覆盖。
5. 下载支持 Range。
6. 网页文件 API 的普通删除进入系统数据目录回收站；恢复可使用原路径或指定新路径，永久清理需要二次确认。
7. 同一来源移动和跨来源移动均可用，目标已存在时不覆盖。
8. 文件与目录可复制到当前或其他有写权限的来源；只读来源允许复制但不允许移动。
9. 路径穿越被拒绝。
10. symlink 被拒绝。
11. 排除路径不可访问。
12. 有限额存储源并发写入不会穿透硬配额；覆盖超限保留原文件且不残留上传临时文件。
13. REST、WebDAV、S3 PUT、Multipart Complete、登录用户图床和匿名图床超限均返回各自协议的 507。
14. 复制同时受目标来源配额和执行用户配额约束；跨来源移动受目标来源配额约束且不会重复计算用户用量。
15. 跨来源移动保留文件台账归属，图床记录跟随目标来源和路径，公开图片 URL 继续有效。
16. 复制/移动目录遇到排除路径、symlink 或不支持类型时整体失败，不留下目标残片。
17. 回收站不污染用户存储源；删除释放来源配额但仍占用户配额，恢复检查来源配额，永久清理释放用户配额。
18. 普通用户只能看到和操作自己删除的条目；管理员可管理来源内全部条目，来源回收站非空时禁止删除来源配置。
19. 图床图片移入回收站后历史墙和公开 URL 暂时不可用；恢复后原 URL 重新有效，永久清理后记录删除。
20. 全局搜索可按文件名或相对路径跨全部可访问来源查询，也可筛选单个来源并分页；双字中文关键字可用。
21. 上传、重命名、移动、回收、恢复和永久清理会即时同步搜索索引；外部新增文件在台账校准后可搜索。
22. 搜索不返回禁用来源、无权来源、排除路径或回收站条目，结果不泄露服务器绝对路径；下载与打开目录继续执行实时安全检查。

### 文件与目录分享

1. 对目标文件或整个目录子树具备写权限的用户可以创建随机分享；只读用户不能创建。
2. 文件和目录分享均可公开访问；目录只能浏览其根目录以内的子路径，路径穿越、排除路径和 symlink 被拒绝。
3. 可选密码、有效期和下载次数上限生效；密码只存 bcrypt 哈希，解锁会话只存 Token 哈希。
4. 密码错误按 IP 与分享限流；公开侧不能区分撤销、过期、次数耗尽、回收中、禁用来源和目标缺失。
5. 并发下载不会超过次数上限；HEAD 不消耗次数，Range GET 只计一次。
6. 创建者可以在 `/app/shares` 复制和撤销自己的分享，管理员可以管理全部分享；撤销立即使链接失效。
7. 同源重命名/移动和跨来源移动后链接继续指向目标；复制不复制分享。
8. 移入回收站时链接暂时失效，恢复到原路径或新路径后重新有效，永久清理后分享删除。
9. 存储源禁用或删除、创建者删除后关联分享不可访问，任何情况都不删除额外真实文件。
10. 分享创建、撤销与匿名下载写入审计，密码和明文会话 Token 不进入日志。

### 公开网盘

1. `/` 是公开网盘首页。
2. `/p/*` 可浏览公开目录。
3. `/raw/*` 可访问公开文件。
4. public_mount_path 与公开 URL 不暴露存储源内部 key。
5. 修改 public_mount_path 后，旧目录页和 raw 链接重定向到新路径；禁用公开访问或存储源后旧链接不可访问。

### WebDAV

1. `/dav` 可显示可访问存储源。
2. 系统提供的 `/dav/{storage_key}` 地址可直接挂载，界面用存储源名称描述它。
3. Basic Auth 使用 WebDAV Token。
4. 登录密码不能作为 WebDAV Token 使用。
5. 基础方法可用。
6. 未实现方法返回 501。

### 1.0.0 / V1 WebDAV 持久锁

1. `OPTIONS` 声明 DAV class 2，并列出 `LOCK / UNLOCK`。
2. 独占写锁在进程重启后仍有效，过期后自动清理。
3. `Depth: infinity` 锁会保护全部后代路径，未提交 Token 的写操作返回 423。
4. REST、图床等非 WebDAV 写入口不能绕过持久锁。
5. 携带匹配 Token 的 `PUT / MKCOL / DELETE / MOVE` 可以执行。
6. 锁可刷新、可通过 `PROPFIND` 发现，并且只有创建者可以解锁。
7. 对不存在 URL 加锁会创建零字节普通文件。
8. `DELETE` 清理已删除资源的锁，`MOVE` 不把源资源的锁迁移到目标路径，且不误删外部祖先锁。

### 图床

1. 登录用户可选择默认图床目标。
2. 图床只允许真实图片格式。
3. 图床 URL 为 `/i/{image_id}.{ext}`。
4. 图床历史按用户隔离。
5. PicGo 接口可上传。
6. 删除图床图片同时删除物理文件和记录。
7. 匿名图床默认关闭。
8. 匿名图床开启后可上传。
9. 匿名图床有限流。
10. 匿名用户不能删除图片。

### 1.0.0 / V1 图床缩略图

1. 图床历史响应包含 `thumbnail_url`，页面预览不再下载原图。
2. `GET /t/{image_id}.jpg` 返回最长边不超过 480px 的 JPEG，并支持 ETag 条件请求。
3. 原图 size 或 modTime 变化后不复用旧缓存，同一原图的并发请求不重复生成。
4. 缓存只写入系统 `cache/thumbnails/`，用户存储源中不产生缩略图或 sidecar。
5. 超过 30 天未访问的缓存会在启动时及每日清理；禁用存储源后缩略图返回 404。

### 1.0.0 / V1 S3

1. `s3_enabled=false` 时不监听专用端口；显式启用时只在 `s3_addr` 启动 Path-style 服务。
2. 用户可创建多个独立 Access/Secret，Secret 只展示一次并以 AES-256-GCM 加密保存。
3. master key 可由 `OMNISTORE_MASTER_KEY` 提供；本地生成的 key 会进入系统配置包。
4. Authorization Header 和预签名 URL 的 Signature V4 可用，错误签名、过期请求与禁用凭据被拒绝。
5. ListBuckets、HeadBucket、ListObjectsV2、Head/Get/Put/DeleteObject 和 DeleteObjects 可用。
6. GET 支持 Range；PUT 支持普通 payload、`UNSIGNED-PAYLOAD` 和 unsigned aws-chunked trailer 校验。
7. S3 复用用户存储源读写权限；禁用存储源、排除路径、symlink 和只读写入均不可绕过。
8. S3 写操作不能绕过 WebDAV 持久锁，并写入 `entry_type=s3` 审计日志。
9. 不支持的 ACL、Policy 等操作返回 S3 XML `NotImplemented`，不伪装成功。

### 1.0.0 / V1 S3 Multipart

1. CreateMultipartUpload、UploadPart、ListParts、CompleteMultipartUpload 与 AbortMultipartUpload 可用。
2. UploadId 绑定用户、存储源和对象 Key，其他用户或对象不能复用。
3. PartNumber 限制为 1–10000，同号 Part 可覆盖；完成时校验严格递增顺序、ETag 和非末片 5 MiB 下限。
4. ListParts 支持 marker 与最多 1000 条分页；完成时只逐片流式读取，不把整个对象载入内存。
5. 完成写入复用统一文件服务，不能绕过排除规则、symlink 拒绝和 WebDAV 持久锁。
6. 完成或 Abort 后清理 SQLite 状态与临时目录；失败可重试，超过 24 小时未活动的状态和孤儿目录自动清理。

### 安全

1. Cookie HttpOnly。
2. SameSite=Lax。
3. 写 API 校验 CSRF。
4. 默认不开放 CORS。
5. trusted proxy 生效。
6. Token 只保存哈希。
7. 密码只保存哈希。
8. 明文 Token 只展示一次。

### 审计

1. 登录事件记录。
2. 用户管理记录。
3. 存储源管理记录。
4. 访问策略变更记录。
5. 文件写操作记录。
6. 图床上传记录。
7. 匿名图床上传记录。
8. 审计日志最多保留 10000 条默认值生效。

### 1.0.0 / V1 配置导出

1. 只有超级管理员可以导出系统配置包。
2. 导出包包含生效配置、可打开的 SQLite 一致性快照、恢复说明与 keys 普通文件。
3. 导出包不包含存储源真实文件、缓存、临时上传文件或日志。
4. keys 下的符号链接不会被跟随或导出。
5. 导出响应禁止缓存，临时 ZIP 在请求结束后清理。
6. 导出成功与失败均写入管理审计日志。
